# 📖 readability-checker

中文文案可读性测试工具 - 评估文案是否适合小学五年级学生理解

## 功能

- 🔍 **可读性评分** (1-10分)
- 📝 **复杂句子识别** - 找出难以理解的句子
- 🔤 **难词识别** - 标出超出年级词汇范围的词语
- 💡 **改进建议** - 提供具体优化方向

## 安装

```bash
pip install .
```

## 配置

工具会自动从以下位置查找API配置（按优先级）：

1. `~/.hermes/config.yaml`（与Hermes共享配置）
2. 当前目录的 `config.yaml`
3. 环境变量 `MINIMAX_API_KEY`

## 使用

### 命令行

```bash
# 直接传入文案
readability-cli -t "这是一段要测试的文案"

# 从文件读取
readability-cli -f ./文案.txt
```

### 网页界面

```bash
streamlit run src/readability/web.py
```

然后在浏览器打开 http://localhost:8501

## 示例输出

```
============================================================
📊 可读性评分: 7/10
   7分：五年级学生基本能看懂，少量词汇可能有困难
============================================================

📝 这段文案整体表达清晰，但包含2个专业术语可能需要解释。

🔍 复杂句子:
  1. 由于本产品采用先进的模块化设计理念...
     问题: 句子过长，包含多个修饰成分
     建议: 拆分为短句，或用"因为...所以..."结构

🔤 难词列表:
  1. 模块化
     原因: 技术术语
     替代: 把产品分成几个独立部分

💡 改进建议:
  1. 将长句拆分成短句
  2. 对专业术语加括号解释

============================================================
```

## 开发

```bash
# 安装开发依赖
pip install -e ".[dev]"

# 运行测试
pytest

# 本地运行CLI
python -m readability.cli
```
