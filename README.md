# 📖 readability-checker

中文文案可读性测试工具 - 评估文案是否适合小学五年级学生理解

## 功能

- 🔍 **可读性评分** (1-10分)
- 📝 **复杂句子识别** - 找出难以理解的句子
- 🔤 **难词识别** - 标出超出年级词汇范围的词语
- 💡 **改进建议** - 提供具体优化方向

## 安装

```bash
pip3 install .
```

或者使用 pipx（推荐）：

```bash
pipx install .
```

## 配置

工具会自动从以下位置查找API配置（按优先级）：

1. `~/.hermes/config.yaml`（与Hermes共享配置）
2. 当前目录的 `config.yaml`
3. 环境变量 `MINIMAX_API_KEY`

MiniMax API 地址：`https://api.minimaxi.com/anthropic/v1`

## 使用

### 命令行

```bash
# 直接传入文案
readability-cli -t "这是一段要测试的文案"

# 从文件读取
readability-cli -f ./文案.txt

# 不使用彩色输出
readability-cli -t "文案" --no-color
```

### 网页界面

```bash
streamlit run src/readability/web.py
```

然后在浏览器打开 http://localhost:8501

📝 文案整体采用口语化叙事风格，故事化表达较为生动形象。但包含多个专业概念超出小学阶段认知水平。

  1. 行为经济学
     原因: 专业学科名称
     替代: 可以说'研究人怎么做决定的学问'

  2. 心理账户
     原因: 行为经济学核心概念
     替代: 可以说'心里给钱分的箱子'

💡 改进建议:
  1. 将专业术语替换为更形象的比喻
  2. 简化抽象表达，用具体情境替代
  3. 将书面词替换为口语表达

## 评分标准

| 评分 | 等级 | 说明 |
|------|------|------|
| 9-10 | 优秀 | 小学五年级学生完全可以理解 |
| 7-8 | 良好 | 少量词汇可能有困难，整体能看懂 |
| 5-6 | 一般 | 理解有一定难度，需要辅导 |
| 3-4 | 较难 | 大部分内容难以理解 |
| 1-2 | 困难 | 严重超出年级水平 |

## 开发

```bash
# 安装开发依赖
pip3 install -e ".[dev]"

# 运行测试
pytest

# 本地运行CLI
python -m readability.cli
```

- **API**: MiniMax Anthropic 兼容 API
- **SDK**: anthropic Python SDK
- **Web**: Streamlit
- **CLI**: Click
- **数据模型**: Pydantic
